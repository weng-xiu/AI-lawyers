# 12348热线话务系统 V2.0 - 产品需求文档（基于原型优化）

## Overview
- **Summary**: 基于5张高保真原型图，对现有12348热线话务系统进行UI/UX升级和功能扩展，包括新增话务功能面板、来电弹屏、台账记录3个核心页面，优化工作台、工单管理等现有页面，打造完整的12348坐席工作台体验
- **Purpose**: 以广东12348司法行政系统为参照标准，构建专业、高效、符合司法系统使用习惯的话务系统，提升坐席人员工作效率
- **Target Users**: 12348热线坐席人员、工单处理人员、质检人员、管理人员

## Goals
- 实现5大核心页面：工作台、话务功能面板、来电弹屏、工单管理、台账记录
- 新增排队信息、技能组、智能来电分析、流转记录等专业功能
- 优化UI风格：深蓝色顶栏+左侧菜单+浅灰白主内容，符合司法政务系统设计规范
- 完善工单全流程管理：待处理/处理中/已办结三态统计 + 侧滑详情 + 流转时间线
- 新增台账记录功能：模板选择、自动填充、满意度评价、转工单

## Non-Goals (Out of Scope)
- 不实现实际CTI电话交换、IVR语音导航、通话录音等硬件对接功能
- 不实现实时语音识别、声纹识别等AI语音能力
- 不实现短信/外呼通知功能
- 不实现质检评分的详细评分配置

## Background & Context
- 现有系统基于RuoYi框架，已有坐席管理、来电记录、工单管理、咨询转接基础功能
- 参考广东12348公共法律服务热线系统设计风格和功能架构
- 系统采用前后端分离，Java+Vue技术栈，MySQL数据库
- 后端代码在ai-admin/ai-system模块，前端在ai-ui模块

## Functional Requirements

### FR-1: 工作台页面优化
- 顶部欢迎横幅：当前坐席姓名、日期、今日服务数、满意度
- 4个个人统计卡片：总通话数、通话时长、服务满意度、在线时长（带同比变化箭头）
- 团队概览：团队总通话、平均通话时长、团队满意度、平均在线时长
- 公告通知列表：支持查看全部
- 快捷入口：语音咨询、图文咨询、视频咨询、外呼服务、工单登记、台账填写、知识检索、回访任务
- 最近通话记录：列表展示，支持按日期筛选

### FR-2: 话务功能面板（新增）
- 坐席状态条：当前状态（空闲/置闲/置忙/小休/会议/培训）、签入/签出时间
- 等待来电区：深蓝色大横幅，显示等待状态和等待时长
- 功能按钮区：签入、签出、外呼、保持/恢复、转移、咨询、三方通话、话后整理、挂机
- 排队信息：等待列表（号码、咨询类型、等待时长）、平均等待时长
- 今日话务统计：已接通、未接、外呼、平均时长 + 小时话务分布柱状图 + 客户满意度
- 技能组信息：各技能组坐席在线情况进度条

### FR-3: 来电弹屏页面（新增）
- 来电横幅：绿色渐变背景，显示来电号码、归属地、IVR分类、通话时长、接通时间
- 来电人信息卡：头像、姓名、电话、归属地、来电次数、标签（高价值客户等）
- 历史记录Tab：历史通话、历史工单、来电轨迹、用户画像
- 智能来电分析：来电意图预测（置信度）、咨询偏好、高频问题
- 情绪预警：异常来电提醒
- 推荐知识文章
- 底部操作栏：保持通话、转移来电、咨询同事、三方通话、一键登记台账、接入智能助手

### FR-4: 工单管理优化
- 三态统计卡片：待处理、处理中、已办结
- 多条件筛选：工单状态、业务类型、时间范围、紧急程度
- 工单列表：工单号、标题、业务类型、申请人、当前环节、紧急程度、创建时间
- 侧滑详情面板：
  - 工单基本信息：标题、业务类型、申请人、联系电话、创建时间、办结时限、紧急程度、创建人
  - 问题描述
  - 流转记录时间线：工单创建、初审中、复审、指派承办、办结等节点
  - 操作按钮

### FR-5: 台账记录页面（新增）
- 左侧主区：
  - 台账模板选择（法律咨询台账等）
  - 自动填充信息区：来电号码、来电人、服务渠道、接入时间、咨询类型（IVR）
  - 台账内容区：咨询内容摘要、处理结果、满意度评价（星级）、是否转工单开关、附件上传
- 右侧历史台账：
  - 统计：今日、本周、待转工单
  - 搜索+状态筛选
  - 台账列表（工单号、类型、摘要、状态、时间）
  - 操作：查看、编辑、转工单

### FR-6: 导航与布局优化
- 深蓝色顶部导航：左侧12348 Logo、中间坐席信息（头像+姓名+在线状态）、搜索框、通知、设置
- 左侧深色菜单，分5组：
  - 工作台
  - 话务服务：话务功能面板、来电弹屏、（在线服务：图文服务、视频服务）
  - 业务管理：工单管理、台账记录、通话录音、会话记录
  - 回访与支持：未接来电、回访管理、知识库
- 面包屑导航
- 整体配色：深蓝顶栏 `#1e3a8a`、深灰侧边栏 `#1e293b`、浅灰背景 `#f1f5f9`

## Non-Functional Requirements
- **NFR-1**: 页面首屏加载 < 2秒
- **NFR-2**: 侧滑面板、Tab切换等交互响应 < 300ms
- **NFR-3**: 支持100+坐席同时在线操作
- **NFR-4**: 界面文字字号≥12px，对比度符合WCAG AA标准
- **NFR-5**: 所有列表支持分页，默认每页10/20条

## Constraints
- **Technical**: Vue 2 + Element UI + ECharts，兼容RuoYi现有框架
- **Business**: 符合12348热线服务规范和司法行政系统视觉规范
- **Dependencies**: 复用现有坐席、来电记录、工单等后端接口，新增台账等接口

## Assumptions
- 现有后端API可扩展支持新功能数据结构
- 坐席用户已关联技能组配置
- 工单流转节点已配置完成

## Acceptance Criteria

### AC-1: 工作台页面完整呈现
- **Given**: 坐席已登录系统
- **When**: 进入工作台页面
- **Then**: 显示欢迎横幅、4个个人统计卡、团队概览、公告通知、快捷入口、最近通话记录7个模块
- **Verification**: `human-judgment`

### AC-2: 话务功能面板可用
- **Given**: 坐席已签入
- **When**: 进入话务功能面板
- **Then**: 显示状态切换、等待来电区、功能按钮、排队信息、今日统计、技能组信息6个区域
- **Verification**: `human-judgment`

### AC-3: 来电弹屏信息完整
- **Given**: 有来电接入
- **When**: 打开来电弹屏页面
- **Then**: 显示来电横幅、来电人信息、历史记录Tab、智能分析、底部操作栏
- **Verification**: `human-judgment`

### AC-4: 工单管理侧滑详情
- **Given**: 工单列表有数据
- **When**: 点击某条工单
- **Then**: 从右侧滑出详情面板，显示基本信息、问题描述、流转记录时间线
- **Verification**: `human-judgment`

### AC-5: 台账记录双栏布局
- **Given**: 进入台账记录页面
- **When**: 页面加载完成
- **Then**: 左侧为台账填写区（模板选择+自动填充+内容编辑），右侧为历史台账列表
- **Verification**: `human-judgment`

### AC-6: 整体UI风格统一
- **Given**: 系统任意页面
- **When**: 浏览各功能模块
- **Then**: 深蓝顶栏、深灰侧栏、浅灰背景、白色卡片，风格一致，符合司法系统视觉规范
- **Verification**: `human-judgment`
